# 调度模式智能体团队

一个 DSH 桌面端插件 + 一个 agent 预设。它把官方实验性的 Agent Teams 改造成一套
「先把需求问清楚，再动手」的团队工作方式。

## 它给你什么

- **调度模式（dispatch-mode）预设**：Lead 先轮番把需求问清楚再落地 —— 每一轮把问题一次列完，
  用聊天界面的提问卡片（选项 + 推荐项）问你，你点选提交；没有静默假设、用户确认共享理解之前不动手。
- **12 个角色**按工作流阶段排列（按需叫、不必叫满）：外部调研、探索调研、前沿审查、计划审查、
  执行落地、集成落地、复现回归、逻辑审查、对抗审查、美术审查、反思优化、文档术语。
- **统一或逐角色配置**：插件详情页可以一次性给全部角色统一模型与思考强度，也可以逐角色单独指定；
  每个角色还能各自选 agent 预设（PTC / 标准 / 极简灰度）与「批量调用」档。
- **队员的能力面自动收窄**：自动摘掉目标工具与子代理工具，只保留它本职需要的团队工具。
- **结构化汇报**：队员做完必须调 `report_result`（状态 / 证据 / 验收 / 未决项），插件把它投递给 Lead。
- **两个入口看团队**：左侧栏的「智能体团队」一行，或会话成员面板里的「进入工作区」按钮，
  都能打开团队拓扑画布（真实承接关系、运行数据、共享任务、队员对话）。
- **/team 开关**：默认关闭（团队会真的多花模型预算）。开关按会话记忆，宿主重启后会自动把开过团的会话装回来。

## 不做什么

- 不改官方 Agent Teams 的实现，也不替代它 —— 官方那套照常可用，本插件是叠加在上面的用法层。
- 不引入新的模型调用通道：队员的模型与强度最终仍走官方 `agent/request` 覆盖。
